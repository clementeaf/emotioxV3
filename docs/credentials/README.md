# Credentials

This directory contains sensitive credential files that are **NOT tracked in git**.

## Files

- `cefal_accessKeys.csv` - AWS access keys (not tracked)
- `cefal_credentials.csv` - Credentials file (not tracked)
- `client_secret_*.json` - Google OAuth client secrets (not tracked)

**⚠️ WARNING**: These files contain sensitive information and are excluded from version control via `.gitignore`.
