# Migration Documentation

- `MIGRATION_CREDENTIALS.md` - Migration credentials (not tracked in git)
- `MIGRATION_DNS_VALIDATION.md` - DNS validation documentation
- `MIGRATION_INDEX.md` - Migration index
- `MIGRATION_NAMING_STRATEGY.md` - Naming strategy for migrations
- `MIGRATION_PLAN.md` - Overall migration plan
- `MIGRATION_PORTABILITY_SUMMARY.md` - Portability summary
- `MIGRATION_PROGRESS_REPORT.md` - Progress report
- `MIGRATION_QUICKSTART.md` - Quick start guide
- `MIGRATION_SUMMARY.md` - Migration summary
